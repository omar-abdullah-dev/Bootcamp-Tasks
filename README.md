## IOC Task
This repository also includes an IoC (Inversion of Control) task that demonstrates Spring-style bean configuration and object dependency management. The task is organized under the `src/IoCTask` package and includes shape classes such as `CircleShape`, `RectangleShape`, and `TriangleShape`.
